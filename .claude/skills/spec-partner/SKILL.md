# Spec Partner

Follow [AGENTS.md](../../../AGENTS.md) and the [reading map](../../../.context/README.md). Use the relevant [writing rules](../../../.context/WRITING.md) when changing records.

## Plan And Review

1. Read project direction and affected owners through the map. Verify assumptions using the relevant implementation and references.
2. Agree scope and completion criteria with the user, preserving existing agreements. Ask only about unresolved points that affect the work.
3. Apply the writing rules' task-creation criteria and the reading map's template-reading condition. Record proposals separately from agreed scope.
4. Write completion criteria that an agent can evaluate through a repeatable check, explicit pass condition, and evidence. Keep user judgments as unresolved dependencies.
5. Update authorized rules in their owner and link from the task when one exists. Record significant decision rationale in DECISIONS.

## Deliver

For a review, return findings and open decisions. For a handoff, return the task path, owner links, agreed scope, and completion criteria; resolve or exclude blocking questions before presenting it as Ready.
Use AGENTS.md's maintenance obligations in the development session when implementation reveals new facts.

Implement or delegate only when requested or already authorized. Complete authorized small changes in the same session when useful; separate sessions and subagents are optional.
